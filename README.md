## Selected projects

### 01 · Marchés Publics Analytics

**French public procurement data, from ingestion to exploration.**

An end-to-end ETL pipeline that ingests **DECP** public procurement records, enriches them with **SIRENE** company data and **API Geo** geographic data, and makes the results available for analysis.

`DECP → SIRENE + API Geo enrichment → DuckDB + dbt → Streamlit`

- **Ingest & enrich:** combine procurement records with company and geographic context.
- **Store & transform:** use a **DuckDB** warehouse and **dbt** transformations.
- **Explore:** surface insights through a **Streamlit** dashboard.

**Stack:** DECP · SIRENE · API Geo · DuckDB · dbt · Streamlit

**Repository:** (https://github.com/islambelhardi/marches-publics-etl)

### 02 · LexRAG

**French civil law answers with sources attached.**

A portfolio RAG system that answers questions about French civil law by retrieving relevant articles from the **Code civil** and generating **grounded answers with citations**.

`Question → Article retrieval → Grounded generation → Answer + citations`

- **Retrieve:** find relevant articles in the French Code civil.
- **Ground:** use retrieved legal text as context for answer generation.
- **Cite:** connect answers to supporting articles so readers can consult the source.

**Focus:** Retrieval-Augmented Generation · French legal text · Source-grounded answers

**Repository:** (https://github.com/islambelhardi/LexRAG)
